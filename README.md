# task26100115-b

进程内福利额度账本库（Go）。单组织、固定员工数、整数分、无持久化。

- 每名员工每期发放 10000 分；第 p 期资金仅可在第 p、p+1 期使用。
- `Submit` 立即预占（较早来源优先）；`Resolve` 批准/拒绝/取消；终态不可变。
- `Advance` 原子推进一期：跨期申请整笔自动取消（有效部分返还、过期部分计入已过期），
  未预占过期余额计入已过期，已消费不再结转。
- `Snapshot` 返回同一瞬间的全组织一致视图。

## 并发设计

- 每员工一把锁；单员工操作不触碰其他员工状态。
- 全局仅有极小的 publish 临界区（期号校验 + 指针发布 + 时钟递增），
  不覆盖资金计算、员工遍历或员工锁等待。
- `Advance` 为惰性原子切换（O(1) 追加跨期记录，不取员工锁）；
  员工状态在下次访问时按纯函数迁移。
- `Snapshot` 基于 MVCC 版本链读取一致时钟切面，不加锁、不阻塞写入。

## 运行测试

```sh
go test -race ./...
```
